# IHBI Test Series

## Overview

IHBI Test Series is a web-based examination and performance tracking platform designed for students, teachers, administrators, and parents.

The platform will initially focus on NEET preparation and will later be designed to support other examinations such as JEE.

## Main Goals

- Provide a reliable online test platform.
- Allow teachers to create and manage tests.
- Allow questions to be uploaded efficiently using CSV files.
- Allow students to take timed tests.
- Automatically submit tests when time expires.
- Provide detailed performance analysis.
- Provide rankings at overall, subject, and topic levels.
- Allow parents to monitor their child's performance.
- Generate detailed PDF reports.
- Provide communication between teachers/admins and students/parents.

## User Roles

### Super Admin

Responsible for managing the entire platform.

### Teacher

Responsible for managing students, creating tests, questions, results, and performance analysis according to their permissions.

### Student

Takes tests and views their own results, performance, and rankings.

### Parent

Views the performance, results, progress, and rankings of their linked child.

## Initial Examination

NEET

Initial subjects:

- Physics
- Chemistry
- Biology

## Future Examinations

The system should be designed so additional examinations can be added without rebuilding the core platform.

Potential future examinations:

- JEE
- Other competitive examinations

## Target Devices

The platform must work well on:

- Mobile phones
- Tablets
- Laptops
- Desktop computers

The student test-taking experience should receive particular attention on mobile devices.

## Planned Domain

Production is planned for a subdomain such as:

test.ihbi.in

The exact deployment configuration will be decided later.

## Design Direction

The interface should be:

- Professional
- Clean
- Modern
- Minimal
- Mobile-friendly
- Fast
- Easy to understand

The visual language will take inspiration from the simplicity and consistency of modern Samsung and Apple interfaces without directly copying either design.

The IHBI logo is used as the organization identity, but the website interface is not required to follow the logo's existing color scheme.

## Development Principle

The project should be developed as a real production-oriented application rather than a simple frontend prototype.

Important areas include:

- Security
- Authentication
- Authorization
- Data integrity
- Performance
- Maintainability
- Documentation
- Scalability
